# User Guide

## Current Availability

Orin is in the repository-and-documentation stage. There is no application to install or run yet.
This guide records the intended workflow without presenting planned features as available.

## Intended Workflow

The planned experience follows the [product vision](vision.md):

1. Navigate a project's folders and files through the **Project Explorer**.
2. Give an intention or task to a coding agent through the **Agent Workspace**.
3. Supervise conversations, delegate work, and review progress across agents.
4. Inspect files, changes, and diffs in the **Code Viewer**.
5. Use the **Terminal** to execute commands and interact with the development environment.

These steps describe product intent, not implemented controls or guaranteed interaction sequences.

## Planned Agent Support

Orin aims to unify tools such as **Claude Code**, **Codex**, and **Gemini CLI**.
No agent adapter, conversation handling, authentication flow, or task execution is implemented yet.

## Platforms

The approved targets are desktop applications for Windows, Linux, and macOS.
Minimum operating-system versions, hardware requirements, and installation packages have not been selected.

## Project Data and Settings

Project storage, settings, and agent permissions are not implemented.
Their behavior and any data-handling implications will be documented when application work begins.

## Help and Contributions

Use [Reporting Bugs](../CONTRIBUTING.md#reporting-bugs) for documentation errors and, once implemented, application defects.
Use [Suggesting Features](../CONTRIBUTING.md#suggesting-features) for proposals.
The [development guide](development.md) explains the current repository structure and contribution checks.
